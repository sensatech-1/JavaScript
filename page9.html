Introduction to the DOM

Selecting Elements

- `document.getElementById("id")` - `document.querySelector(".class")` - `document.querySelectorAll("p")` let title = document.getElementById("header"); let items = document.querySelectorAll(".list-item");

Changing Content

- `element.textContent` → text only - `element.innerHTML` → HTML content element.textContent = "Hello!"; element.innerHTML = "Bold text";
