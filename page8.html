Arrays in JavaScript

- Arrays store multiple values in a single variable.
- Ordered and zero-indexed. let fruits = ["Apple", "Banana", "Orange"]; Common Array Methods - push(), pop(), map(), filter() fruits.push("Mango"); let numbers = [1,2,3]; let doubled = numbers.map(n => n * 2);

Objects in JavaScript

- Objects store data as key–value pairs. let user = {
name: "Alex", age: 20, isStudent: true }; Accessing Properties user.name; user["age"];

JSON (JavaScript Object Notation)

- Format for storing and exchanging data - Looks like JS objects { "name": "Alex", "age": 21 } Convert JSON JSON.stringify(user); JSON.parse(jsonText); Exercises 1. Create an array of 5 numbers 2. Create an object describing yourself 3. Convert your object to JSON and back
