01. The Conditional Gates

Control flow is the order in which individual statements are executed. The most common tool is the if statement.

It acts as a gatekeeper: "If this condition is true, let the code pass."

if (age >= 18) {
  console.log("Access Granted");
}

02. The "Else" Backup

What if the condition is false? We use else to provide a fallback plan.

if (isLoggedIn) {
  showDashboard();
} else {
  showLoginPage();
}

03. Multi-Path Logic

When you have more than two options, use else if. This creates a chain of checks.

The computer checks them in order and stops as soon as it finds a true one.

04. Logical Operators

Sometimes one condition isn't enough. We combine them using:

  • && (AND): Both sides must be true.
  • || (OR): At least one side must be true.
  • ! (NOT): Reverses the logic (true becomes false).

06. Truthy and Falsy

In JS, every value has an inherent boolean "vibe."

Falsy values: 0, "" (empty string), null, undefined, and NaN.

Everything else is generally Truthy.

07. The Ternary Operator

This is a "Short-hand" version of if/else. It's great for simple assignments.

let status = (score > 50) ? "Pass" : "Fail";

08. Switch Statements

When comparing one variable against many specific values (like a menu), a switch is cleaner than many else if blocks.

09. Comparison Deep-Dive

Remember === vs ==? Always use Triple Equals. It prevents "Type Coercion" where JS tries to guess what you meant.
